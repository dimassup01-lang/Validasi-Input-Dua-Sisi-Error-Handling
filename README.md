# 🎣 Wo-Tackle

**Sistem Kasir dan Manajemen Inventaris Berbasis Web**

Mbah Wo Tackle adalah aplikasi berbasis web yang dikembangkan untuk membantu operasional Toko Alat Pancing Mbah Wo. Aplikasi ini dirancang untuk mempermudah pengelolaan produk, transaksi penjualan, pembayaran, dan stok barang dalam satu sistem yang terintegrasi.

Sistem ini ditujukan untuk admin dan kasir toko yang memiliki akses resmi. Aplikasi dirancang agar dapat diakses melalui laptop maupun perangkat HP yang terhubung ke jaringan Wi-Fi lokal yang sama.

## ✨ Fitur Utama

- **Manajemen Produk** — Menambahkan, mengedit, mencari, dan mengelola data produk, termasuk nama barang, harga, kode produk, dan jumlah stok.
- **Sistem Kasir** — Memproses transaksi penjualan dengan perhitungan harga dan total pembayaran secara otomatis.
- **Metode Pembayaran** — Mendukung pembayaran tunai dan QRIS dinamis.
- **Pembaruan Stok Otomatis** — Mengurangi jumlah stok barang setelah transaksi berhasil.
- **Struk Digital** — Menampilkan bukti transaksi secara digital tanpa memerlukan printer.
- **Riwayat Transaksi** — Menyimpan data transaksi ke dalam database agar dapat dilihat kembali dan digunakan untuk laporan penjualan.
- **Tampilan Responsif** — Mendukung penggunaan melalui laptop maupun perangkat HP.

## 🛠️ Teknologi yang Digunakan

- **Backend:** PHP
- **Database:** MySQL
- **Lingkungan Pengembangan Lokal:** Laragon
- **Version Control:** Git dan GitHub
- **Frontend:** Disesuaikan dengan teknologi yang digunakan oleh tim.

## 🎯 Tujuan Pengembangan

- Mempermudah dan mempercepat proses transaksi penjualan.
- Mengurangi kesalahan dalam perhitungan pembayaran dan pengelolaan stok.
- Membantu penyimpanan data produk dan transaksi secara terstruktur.
- Menyediakan sistem pengelolaan toko yang praktis dan mudah digunakan.
